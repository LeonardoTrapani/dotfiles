---
name: prototype
description: Use before writing UI code when a request involves a UI choice, or when the user asks for a prototype or mock.
---

A prototype or mock is rough HTML of the UI before it is built.

- **UI.** Every UI point goes in the first reply as a copy of [prototype.html](references/prototype.html), built by its header: one decision per point, Today beside each variant, `FIRST` the thread's next free number. A pattern several pages share is shown once, on a realistic page with all its states.
- **Variants.** Two or three, a better idea than the user's among them. A variant is a different approach, not a slight variation.
- **Show** it with `html_render` (load it with ToolSearch), checked first with `html_preview` at 728 and 360 px.
- **Change nothing** until the user approves in their own words.
