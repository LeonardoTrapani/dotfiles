# Credits

The review loop (budget, ledger, severities, brief) and the end-to-end proof
step follow [Theo Browne](https://github.com/t3dotgg)'s
[`sol-loop`](https://github.com/t3dotgg/tstack/blob/main/skills/sol-loop/SKILL.md)
and [`full-send`](https://github.com/t3dotgg/tstack/blob/main/skills/full-send/SKILL.md)
skills. "Ready only when the user asks" comes from
[Matteo](https://github.com/MP281X)'s
[`pull-requests`](https://github.com/MP281X/deslop/blob/main/.claude/skills/pull-requests/SKILL.md)
skill.
